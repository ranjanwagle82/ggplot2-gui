ggplot2 gui is a simple and user-friendly Shiny application designed to help anyone create beautiful ggplot2 plots without writing code. It features an intuitive interface where you can upload your own CSV or Excel data (or start with the built-in mtcars dataset), choose variables for axes and aesthetics like color, fill, shape, and size, select plot types such as scatter, bar, line, histogram, or smooth, and add faceting, themes, titles, and labels with just a few clicks. 

The app also shows the exact ggplot2 code it generates in real time, making it great for learning or quick prototyping.
You can edit the code directly and update the plot instantly, adjust plot dimensions, and download your visualization as PNG, PDF, or SVG. 

Also included ggplot GUI.bat file makes it easy to launch on Windows (just double-click it and the app will automatically find your R installation), install the shiny package if needed, and open the app in your default browser. This tool is perfect for beginners, students, teachers, or anyone who wants to explore data visually in R without diving deep into coding. It's lightweight, modular, and ready to run locally.
